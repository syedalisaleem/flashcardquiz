Built for how memory actually works

Not just prettier notecards. Every feature is grounded in spaced repetition science.

Atomic cards

Each card tests exactly one fact. The Minimum Information Principle behind SuperMemo and Anki.

Misconception distractors

Wrong MCQ options come from real student mistakes. Each one includes an explanation of why it's incorrect.

Spaced repetition

The SM-2 algorithm schedules each card's next review. Same engine that powers Anki.

One-click Anki export

Native .apkg files with tags, Cloze deletion, and source references. Import into Anki instantly.

Multi-deck workspace

Organize by lecture or subject. Decks persist locally in SQLite across sessions.

Cloud OCR

Snap a photo of any textbook page. ocr.space extracts text in seconds, even from handwritten notes.
